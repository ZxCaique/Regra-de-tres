# 📐 Calculadora de Regra de Três

A **Calculadora de Regra de Três** é uma aplicação web desenvolvida com **HTML, CSS e JavaScript** que permite calcular o valor desconhecido em uma proporção de forma rápida e intuitiva.

O projeto foi criado com o objetivo de praticar os fundamentos do desenvolvimento front-end, incluindo manipulação do DOM, validação de entradas e lógica de programação em JavaScript.

---

## ✨ Funcionalidades

- Cálculo automático de regra de três simples
- Interface simples e intuitiva
- Validação dos campos de entrada
- Resultado exibido instantaneamente
- Layout responsivo

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ▶️ Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/calculadora-regra-de-tres.git
```

### 2. Acesse a pasta

```bash
cd calculadora-regra-de-tres
```

### 3. Abra o arquivo

Abra o arquivo **index.html** em qualquer navegador moderno.

Ou utilize a extensão **Live Server** no Visual Studio Code para executar o projeto.

---

## 📖 Como Utilizar

1. Informe os três valores conhecidos da proporção.
2. Deixe vazio apenas o valor que deseja descobrir.
3. Clique no botão de calcular.
4. O resultado será exibido automaticamente na tela.
